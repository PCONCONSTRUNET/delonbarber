# DELON BARBER

Crie um sistema web inspirado no tema do site Natan Barber, mas adaptado para a Barbearia Alan Delon.  
O sistema deve ser responsivo, moderno e elegante, com tema escuro e fundo animado.  
Use paleta de cores vermelho (#D62828), azul profundo (#003049), azul vivo (#1E90FF), fundo preto (#0B0B0B) e tipografia clássica (Inter para UI e Cinzel/Playfair para títulos).  
Inclua navbar com rotas: Home, Agendar, Serviços, Login.  
Adicione rodapé com © 2026 Barbearia Alan Delon.  
Prepare o sistema como PWA instalável no celular, com ícones e splash screen.  
Configure autenticação de usuários com email/senha e perfis (nome, telefone, avatar).
